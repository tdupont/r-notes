2  R Markdown & Quarto

R Markdown (.Rmd) and its successor Quarto (.qmd) let you weave together prose, code, and output into a single reproducible document. This chapter covers everything you need to author and customise these documents effectively.

2.1 Document structure

Every R Markdown / Quarto document has three parts:

  1. YAML header — metadata at the top, delimited by ---
  2. Text — prose written in Markdown
  3. Code chunks — executable blocks surrounded by backticks

2.1.1 The YAML header

---
title: "My Analysis"
author: "Thibault Dupont"
date: "2026-05-09"
output:
  html_document:
    toc: true
    toc_depth: 2
    toc_float:
      collapsed: false
      smooth_scroll: true
    number_sections: true
---

Key YAML options:

Option Effect
toc: true Adds a table of contents
toc_depth: 2 TOC shows headers up to ## only
toc_float TOC floats on the left side while scrolling
number_sections: true Automatically numbers sections

Automatic dates:

date: "2026-05-09"
date: "09 May 2026"
date: "Last edited on: 2026-05-09"

Multiple output formats:

output:
  html_document: default
  pdf_document: default
  word_document: default

2.2 The setup chunk

The first code chunk in a document is usually the setup chunk. It sets global options that apply to every subsequent chunk.

2.3 Code chunks

2.3.1 Essential chunk options

Option Effect
echo = FALSE Hides the code, shows the output
eval = FALSE Shows the code but does not run it
include = FALSE Runs the code silently; no code or output shown
collapse = TRUE Merges code and output into a single block
message = FALSE Suppresses package loading messages
warning = FALSE Suppresses warnings

2.3.2 Figure options

#| fig.width: 8
#| fig.height: 5
#| fig.align: "center"
#| fig.cap: "Distribution of life expectancy by continent"
#| out.width: "70%"

These can also be set globally in the setup chunk.

2.4 Text formatting

2.4.1 Basic Markdown

# Heading 1
## Heading 2
### Heading 3

**bold text**
*italic text*
`inline code`
~~strikethrough~~

- Bullet item
- Another item

1. First numbered item
2. Second numbered item

2.4.2 Links and images

[Link text](https://www.example.com)
![Alt text](path/to/image.png)

2.4.3 Inline R code

Embed a variable directly in text by opening a backtick, writing the letter r followed by a space, then any R expression, then a closing backtick. For example, writing nrow(df) as an inline expression will print the number of rows directly in your sentence: The model included 248 patients.

2.5 Parameterised reports

Parameters make it easy to re-run the same report for different subgroups or time periods without editing the code.

Define parameters in YAML:

params:
  country: "France"
  year: 2023
  start_date: "2023-01-01"

Use them in code:

params$country
params$year

Use them in text by embedding inline R expressions in your prose — for example, params$country and params$year inserted inline will print the parameter values directly into the sentence when the document is rendered.

2.6 Custom styling

2.6.1 Inline CSS

Add a <style> block anywhere in the document to customise appearance.

<style>
body {
  color: #2c3e50;
  font-family: "Helvetica Neue", sans-serif;
  background-color: #f8f9fa;
}

pre {
  background-color: #f0f0f0;
}

#TOC {
  color: #2980b9;
  font-size: 14px;
}
</style>

2.6.2 External CSS file

Reference a stylesheet from the YAML header to keep the document clean:

output:
  html_document:
    css: styles.css

2.7 Output types

Format YAML key Notes
HTML html_document Best for interactive viewing; supports floating TOC
PDF pdf_document Requires a LaTeX installation (e.g. TinyTeX)
Word word_document Use reference_docx to apply a template
Notebook html_notebook Adds a preview button in RStudio

Word template:

output:
  word_document:
    reference_docx: template.docx
    toc: true
